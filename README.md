# LumenChess

Offline-first Android chess app focused on engine play, Engine Arena, local Game Review, Analysis, Explorer, imports/sync, and deep customization.

## Current state

Design/specification complete enough for implementation planning. Production implementation has not started.

Primary initial target: Pixel 8 Pro, Android 17/API 37, ARM64.  
Initial engines: Stockfish + Reckless.  
Initial chess modes: Standard + Chess960.  
Default accent: blue.

## Public-reference policy

Raw Chess.com screenshots and the scraped Chess.com sound-reference archive used during planning are intentionally not committed here because redistribution rights are not established. The repository should contain only original/public-safe project material unless licensing is verified.
